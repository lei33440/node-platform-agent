# Changelog

## 0.2.0 - 2026-09-05

- Added a one-time control-plane enrollment flow for new machines.
- Added automatic Agent URL derivation from the configured machine address and
  Agent HTTPS port.
- Added per-machine Agent tokens and per-machine TLS CAs.
- Added Debian/Ubuntu installer support for Node.js, Xray, systemd, UFW, and
  Xray release SHA-256 verification.
- Added support for machine-specific node TCP port ranges.
- Added operational, update, uninstall, and security documentation.

## 0.1.0 - 2026-09-05

- Initial public Agent source and traffic-counter reconciliation helper.
